# GitHub & AI Practice (SWE 325/525 – Lab 8)

This repository is for **Lab 8: GitHub Issues**. It practices the standard GitHub workflow (issues, feature branches, commits, and pull requests) and keeps a record of how AI tools were used during the work.

## Contents

- `README.md`: overview of the repository and lab requirements
- `ai-log.md`: record of AI prompts and responses, noting which suggestions were accepted, revised, or rejected

## Lab Requirements

- [ ] The repository has a useful README.md
- [ ] The change is developed on a feature branch
- [ ] The feature branch contains at least three meaningful commits
- [ ] The pull request includes a summary, issue link, and evidence
- [ ] The AI-use record identifies accepted, revised, and rejected suggestions
